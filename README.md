# 열지기

**주소: https://larry250522.github.io/yeoljigi/** (GitHub Pages — main 에 push 하면 몇 분 뒤 바뀐다)

아이가 열날 때 쓰는 웹앱(PWA). 체온 · 해열제 · 증상을 남기면 **다음 해열제를 언제부터, 얼마나** 먹일 수 있는지 계열마다
셉니다. 가입 없이, 기록은 그 휴대폰에만. 카카오톡 링크로 나눠 쓰는 것을 생각해 만들었습니다.

## 하는 일

| 화면 | 내용 |
|---|---|
| 홈 | 마지막 체온(구간 색) · 앞 체온보다 오르내림 · 24시간 최고 · 이번 열이 몇 시간째인지 · 체온에 맞춘 한 줄 안내 · 빠른 기록(체온 · 해열제 · 증상 · **소변 한 번 누르기**) · 계열마다 다음 해열제(남은 시간, 24시간 횟수, **24시간 남은 양**) · 최근 24시간 그래프 · 바로 병원에 가야 할 때 알림 |
| 기록 | 체온 · 해열제 · 증상을 날짜별로, 그래프 24시간 · 3일 · 7일. 눌러서 고치거나 지우기(되돌리기) |
| 용량 | 약 · 몸무게로 1회 양(mL), 간격, 하루 최대량, 먹이는 나이 |
| 설정 | 아이(생년월일 · 몸무게 · 열성 경련 · 알레르기), 내 약(성분 · 함량), 알림, 테마, 백업 파일 저장 · 불러오기, 도움말 |
| 진료용 요약 | 최근 72시간 기록을 글로 — 복사하거나 공유 시트로 카카오톡 등에 보내기. **그래프 그림(PNG)** 으로도 |
| 가족에게 | 해열제를 기록하면 바로 「가족에게」 — 먹인 약 · 양과 계열마다 다음에 먹일 수 있는 때를 글로 보낸다(다른 보호자가 또 먹이지 않게) |

해열제 계산 (`js/dose.js` 한 곳)

- 아세트아미노펜 계열 / 이부프로펜 계열(이부프로펜 · 덱시부프로펜 — **같은 계열**로 센다).
- 같은 계열 간격(4시간 · 6시간), 다른 계열과 2시간, 24시간 횟수(5번 · 4번), 하루 최대량 — 모두 **직전 24시간**으로 센다(자정에 다시 세지 않는다).
- 1회 양은 체중 × mg/kg, 어른 1회 최대량을 넘지 않게. 생후 3개월 미만 · 이부프로펜 6개월 미만은 경고.
- 숫자는 국내 어린이 해열제 포장 설명서의 일반 범위. 화면은 늘 「포장 설명서와 의사 · 약사의 지시가 먼저」.

## 켜기 · 시험

```sh
npm run serve      # http://127.0.0.1:8811
```

## 알아 둘 것

- **카카오톡 안 브라우저**에서는 홈 화면 추가 · 알림 · 오프라인이 안 되고, 기록도 기본 브라우저와 따로 저장됩니다. 그래서 열리자마자
  기본 브라우저로 넘깁니다(`kakaotalk://web/openExternal` — 비공식이라 안 되면 화면의 「열기」 단추).
- **알림**은 앱이 열려 있거나 뒤에 남아 있을 때만 울립니다(웹은 닫힌 앱의 예약 알림이 없음). iOS 는 홈 화면에 추가해야 알림을 받습니다.
- 기록은 그 브라우저에만 있습니다. 휴대폰을 바꿀 때는 설정 → 백업 파일 저장 → 새 폰에서 불러오기.
- 판을 올릴 때 `js/env.js` 의 `VERSION` 과 `sw.js` 의 `CACHE` 를 함께 바꿉니다.

## 허가사항 대조 (2026-10-11)

맞음 — 원문을 확인했다:
- 아세트아미노펜 — 「1회 10~15mg/kg」 · 「4-6시간 마다」 · 「1일 5회(75mg/kg)를 초과하지 않는다」, 표는 4개월부터, 32mg/mL
  (어린이타이레놀현탁액 · 챔프시럽 · 콜대원키즈펜).
- 이부프로펜 — 「체중이 30kg미만인 어린이는 1일량이 500mg(25ml)을 초과해서는 안되며」(라미돈시럽 · 챔프이부펜 · 콜대원키즈이부펜).
  어린이부루펜시럽 원문에는 이 문장이 없다. 앱은 더 보수적인 500mg 을 쓴다.
- 덱시부프로펜 — 「1회 5~7mg/kg … 1일 최대 4회(28mg/kg)」(맥시부펜시럽 nedrug), 30kg 이하 하루 300mg(한미 제품 안내).
  허가 간격은 4~6시간이지만 앱은 6시간(식약처 2025-12 안내 「6~8시간」과 맞다).
- 같은 계열 번갈아 먹이지 않기 · 다른 계열 2~3시간 — 식약처 2025-12 안내(언론 보도로 확인).

다른 점 — 사용자가 정해 0.4.0 에 반영:
- 이부프로펜 시럽 허가는 mg/kg 이 아니라 **나이별 표**(1~2세 1회 50~100mg · 하루 400mg, 3~6세 100~150 · 600, 7~10세 150~200 · 800,
  11~14세 200~250 · 1000). → 생년월일이 있으면 **체중 계산과 표 중 적은 쪽**(`ageTable`). 표 밖(돌 전 · 만 15세부터)이나 생년월일이
  없으면 체중만. 최소 나이는 6개월 그대로(식약처 2025-12 안내), 도움말에 「포장 표는 1세부터일 수 있음」.
- 좌약(복합써스펜좌약 125mg) 허가는 「1일 2~3회」. → 내 약마다 「하루 최대 횟수」(`maxPerDay`), 새 「개」 단위 약은 3번으로 시작.
  계열의 하루 횟수(5번)도 함께 본다.
- 30kg 경계에서 하루 최대량이 크게 뛴다(이부프로펜 500 → 1200mg, 덱시부프로펜 300 → 843mg). → 허가 문구 그대로 둔다
  (이부프로펜은 나이별 표가 7~14세에서 800 · 1000mg 상한이 된다).

## 근거 (안내 · 경고 문구)

- 영국 NICE NG143 「Fever in under 5s」(2019/2021) — 빨간 · 주황 신호, 3~6개월 39℃, 5일 넘는 열, 해열제는 힘들어할 때만 ·
  한꺼번에 먹이지 않기 · 번갈아는 계속 힘들어할 때만, 경련 예방 못 함, 미지근한 물 닦기 안 함, 잰 곳(귀 · 겨드랑이).
- 미국소아과학회 — Sullivan & Farrar, Pediatrics 2011 「Fever and Antipyretic Use in Children」, HealthyChildren 「When to Call」
  (두 돌 전 24시간 · 그 뒤 72시간).
- 코크란 — Wong 2013(번갈아 · 함께 먹이기), Offringa 2021(경련 예방 못 함).
- 이부프로펜 계열 주의 — 수두(NICE CKS), 탈수 아이의 급성 신손상(Misurac 2013 J Pediatr, Balestracci 2015 Pediatr Nephrol).
- 계량 — Yin 2016 · 2017 Pediatrics(계량컵이 주사기보다 잘못 재는 일이 많다, mL 만).
- 아이 상태 기록 — FeverApp 등록 연구(Möhler 2022 IJERPH), 밤에 더 높은 열(Beerenbrock 2026 BMC Pediatr),
  열 공포(Clericetti 2019 Acta Paediatr), 38℃ 아래 투약(Park 2021 JMIR mHealth — 열나요 자료).
- 국내 — 식약처 2025-12 어린이 해열제 안내, 응급의료 상담은 119(1339 는 지금 질병관리청 민원 창구),
  달빛어린이병원 찾기 e-gen.or.kr/moonlight.

## 참고한 오픈소스 (2026-10 조사 — 아이디어만, 코드는 가져오지 않음)

계열을 묶어 하루 최대량을 mg 비율로 더하고 체중으로 용량까지 세는 오픈소스는 찾지 못했다. 가져온 생각:

- FeverLog(GPL) — 체온 오르내림 표시 · 소변 기록 경고는 Fever-out, 투약 직후 공유 글은 smartdose, 그래프 PNG 는 fiebertagebuch
- 가족 공유를 만들 때: baby-tracker(초대 코드 = 권한, 계정 없음), NestHealth(AGPL — 60초 폴링 · 의존성 없는 VAPID 웹 푸시)
- 라이선스 없는 저장소(fiebertagebuch · smartdose · Fever-out)는 코드를 쓸 권리가 없다
