# 열지기

[![CI](https://github.com/yeoljigi/yeoljigi.github.io/actions/workflows/ci.yml/badge.svg)](https://github.com/yeoljigi/yeoljigi.github.io/actions/workflows/ci.yml)

**주소: https://yeoljigi.github.io/** (GitHub Pages — main 에 push 하면 몇 분 뒤 바뀐다)

아이가 열날 때 쓰는 기록장 웹앱(PWA). 체온 · 해열제 · 증상을 남기고, 계열마다 **마지막으로 먹인 때 · 24시간 횟수**를
포장 설명서 내용과 나란히 보여 줍니다. 먹일 양 · 시각은 **계산하지 않습니다**(아래 「계산하지 않는 이유」). 가입 없이, 기록은
그 휴대폰에만. 카카오톡 링크로 나눠 쓰는 것을 생각해 만들었습니다.

## 하는 일

| 화면 | 내용 |
|---|---|
| 홈 | 마지막 체온(구간 색) · 앞 체온보다 오르내림 · 24시간 최고 · 이번 열이 몇 시간째인지 · 체온에 맞춘 한 줄 안내 · 빠른 기록(체온 · 해열제 · 증상 · **소변 한 번 누르기**) · 계열마다 해열제 기록(마지막으로 먹인 때 · 지난 시간 · 24시간 횟수, 옆에 설명서 간격 · 하루 횟수) · 최근 24시간 그래프 · 바로 병원에 가야 할 때 알림 |
| 기록 | 체온 · 해열제 · 증상을 날짜별로, 그래프 24시간 · 3일 · 7일. 눌러서 고치거나 지우기(되돌리기) |
| 약 안내 | 내 약의 포장 설명서 내용 — 함량, 1회 · 간격 · 하루(허가 문구 그대로), 먹이는 나이, 이부프로펜 나이별 표(이 약 mL 곁에) |
| 설정 | 아이(생년월일 · 몸무게 · 열성 경련 · 알레르기), 내 약(**국내 제품 목록에서 고르기** 또는 성분 · 함량 · 하루 최대 횟수 직접), 알림, 테마, 백업 파일 저장 · 불러오기, 도움말 |
| 진료용 요약 | 최근 72시간 기록을 글로 — 복사하거나 공유 시트로 카카오톡 등에 보내기. **그래프 그림(PNG)** 으로도 |
| 가족에게 | 해열제를 기록하면 바로 「가족에게」 — 먹인 약 · 양과 계열마다 마지막으로 먹인 때를 글로 보낸다(다른 보호자가 또 먹이지 않게) |

해열제 기록 견주기 (`js/dose.js` 한 곳)

- 아세트아미노펜 계열 / 이부프로펜 계열(이부프로펜 · 덱시부프로펜 — **같은 계열**로 센다).
- 해열제를 기록할 때 앞뒤 같은 계열 기록이 간격 안내(4시간 · 6시간)보다 가깝거나, 다른 계열 기록이 2시간 안이거나, 직전 24시간
  기록 수가 설명서 횟수(5번 · 4번)를 넘으면 **기록과 설명서를 나란히 적어 알린다** — 「된다 · 안 된다」고 하지 않고, 저장은 늘 된다.
- 생후 3개월 미만 · 이부프로펜 6개월 미만 · 제품별 먹이는 나이(종합감기약 만 2세), 수두 · 탈수 기록은 알린다.
- 숫자는 국내 어린이 해열제 포장 설명서의 일반 범위. 화면은 늘 「포장 설명서와 의사 · 약사의 지시가 먼저」.

### 계산하지 않는 이유 (0.7.0, 2026-10-17)

0.6.1 까지는 체중 · 나이로 1회 양(mL), 다음 먹일 수 있는 시각, 24시간 남은 양을 셈했다. 식약처 「디지털의료기기 분류 및 등급
지정에 관한 가이드라인」(2025-11)이 디지털의료기기 목적으로 「의약품 권장 용량 및 투입주기 등의 결정 보조」를 적고 있고(예: 인슐린
주입량 계산 2등급), 무료 · 개인 배포도 의료기기법의 「수여」에 들어가서, 보수적으로 **기록 · 설명서 내용 보여 주기**로 줄였다.
기록 · 복용 알림 · 일반 안내 · 그래프는 2020 「모바일 의료용 앱 안전관리 지침」의 「의료기기 아님」 사례와 가깝다.
식약처 「의료기기 해당 여부 검토」(정부24, 처리 10일)에서 계산 기능이 의료기기가 아니라는 답을 받으면 git `09bbd73`(0.6.1)에서
되살릴 수 있다. 공개 자료 조사이며 법률 자문이 아니다.

## 켜기 · 시험

```sh
npm run serve      # http://127.0.0.1:8811
npm test           # node --test (의존성 없음)
npm run smoke      # 연기 시험 — headless Chrome 으로 모든 화면 · 창을 열어 스크립트 오류 확인
npm run icons      # 아이콘 · 링크 미리보기 그림 다시 만들기 (Pillow)
```

GitHub Actions(`.github/workflows/ci.yml`)가 main 과 PR 마다 문법 확인 · `npm test` · `npm run smoke` 를 돌린다. 함께 만들기는 [CONTRIBUTING.md](CONTRIBUTING.md).

## 알아 둘 것

- **카카오톡 안 브라우저**에서는 홈 화면 추가 · 알림 · 오프라인이 안 되고, 기록도 기본 브라우저와 따로 저장됩니다. 그래서 열리자마자
  기본 브라우저로 넘깁니다(`kakaotalk://web/openExternal` — 비공식이라 안 되면 화면의 「열기」 단추).
- **알림**은 해열제 1시간 뒤 「체온 다시 재기」 하나뿐이고(다음 복용 시각 알림은 0.7.0 에서 뺌), 앱이 열려 있거나 뒤에 남아 있을 때만 울립니다(웹은 닫힌 앱의 예약 알림이 없음). iOS 는 홈 화면에 추가해야 알림을 받습니다.
- 기록은 그 브라우저에만 있습니다. 휴대폰을 바꿀 때는 설정 → 백업 파일 저장 → 새 폰에서 불러오기.
- 판을 올릴 때 `js/env.js` 의 `VERSION` 과 `sw.js` 의 `CACHE` 를 함께 바꿉니다.

## 허가사항 대조 (2026-10-11)

0.7.0 부터 앱은 아래 숫자로 셈하지 않고 「약 안내」에 허가 문구 그대로 보여 준다(이부프로펜은 나이별 표, 30kg · 500mg 상한은
지금 허가된 시럽 문구가 아니라 빼고, 덱시부프로펜 30kg 이하 300mg 은 보여 준다). 「다른 점」은 0.4.0~0.6.1 계산 때의 기록.

맞음 — 원문을 확인했다:
- 아세트아미노펜 — 「1회 10~15mg/kg」 · 「4-6시간 마다」 · 「1일 5회(75mg/kg)를 초과하지 않는다」, 표는 4개월부터, 32mg/mL
  (어린이타이레놀현탁액 · 챔프시럽 · 콜대원키즈펜).
- 이부프로펜 — 「체중이 30kg미만인 어린이는 1일량이 500mg(25ml)을 초과해서는 안되며」는 **라미돈시럽(2018 취하)** 의 문구.
  지금 허가된 시럽(어린이부루펜 · 챔프이부펜 · 콜대원키즈이부펜 · 키즈앤펜, nedrug 원문)은 이 문장 대신 나이별 표를 쓴다.
  빼면 느슨해지는 쪽(3~6세 600mg 등)이라 앱은 더 보수적인 상한으로 500mg 을 남겨 둔다.
- 덱시부프로펜 — 「1회 5~7mg/kg … 1일 최대 4회(28mg/kg)」(맥시부펜시럽 nedrug), 30kg 이하 하루 300mg(한미 제품 안내).
  허가 간격은 4~6시간이지만 앱은 6시간(식약처 2025-12 안내 「6~8시간」과 맞다).
- 같은 계열 번갈아 먹이지 않기 · 다른 계열 2~3시간 — 식약처 2025-12 안내(언론 보도로 확인).

다른 점 — 사용자가 정해 0.4.0 에 반영:
- 이부프로펜 시럽 허가는 mg/kg 이 아니라 **나이별 표**(1~2세 1회 50~100mg · 하루 400mg, 3~6세 100~150 · 600, 7~10세 150~200 · 800,
  11~14세 200~250 · 1000). → 생년월일이 있으면 **체중 계산과 표 중 적은 쪽**(`ageTable`). 표 밖(돌 전 · 만 15세부터)이나 생년월일이
  없으면 체중만. 최소 나이는 6개월 그대로(식약처 2025-12 안내), 도움말에 「포장 표는 1세부터일 수 있음」.
- 좌약(복합써스펜좌약 125mg) 허가는 「1일 2~3회」. → 내 약마다 「하루 최대 횟수」(`maxPerDay`), 새 「개」 단위 약은 3번으로 시작.
  계열의 하루 횟수(5번)도 함께 본다.
- 30kg 경계에서 하루 최대량이 크게 뛴다(이부프로펜 500 → 1200mg, 덱시부프로펜 300 → 843mg). → 허가 문구 그대로 둔다
  (이부프로펜은 나이별 표가 7~14세에서 800 · 1000mg 상한이 된다).

## 근거 (안내 · 경고 문구)

- 영국 NICE NG143 「Fever in under 5s」(2019/2021) — 빨간 · 주황 신호, 3~6개월 39℃, 5일 넘는 열, 해열제는 힘들어할 때만 ·
  한꺼번에 먹이지 않기 · 번갈아는 계속 힘들어할 때만, 경련 예방 못 함, 미지근한 물 닦기 안 함, 잰 곳(귀 · 겨드랑이).
- 미국소아과학회 — Sullivan & Farrar, Pediatrics 2011 「Fever and Antipyretic Use in Children」, HealthyChildren 「When to Call」
  (두 돌 전 24시간 · 그 뒤 72시간).
- 코크란 — Wong 2013(번갈아 · 함께 먹이기), Offringa 2021(경련 예방 못 함).
- 이부프로펜 계열 주의 — 수두(NICE CKS), 탈수 아이의 급성 신손상(Misurac 2013 J Pediatr, Balestracci 2015 Pediatr Nephrol).
- 계량 — Yin 2016 · 2017 Pediatrics(계량컵이 주사기보다 잘못 재는 일이 많다, mL 만).
- 아이 상태 기록 — FeverApp 등록 연구(Möhler 2022 IJERPH), 밤에 더 높은 열(Beerenbrock 2026 BMC Pediatr),
  열 공포(Clericetti 2019 Acta Paediatr), 38℃ 아래 투약(Park 2021 JMIR mHealth — 열나요 자료).
- 국내 — 식약처 2025-12 어린이 해열제 안내, 응급의료 상담은 119(1339 는 지금 질병관리청 민원 창구),
  달빛어린이병원 찾기 e-gen.or.kr/moonlight.

## 참고한 오픈소스 (2026-10 조사 — 아이디어만, 코드는 가져오지 않음)

계열을 묶어 하루 최대량을 mg 비율로 더하고 체중으로 용량까지 세는 오픈소스는 찾지 못했다. 가져온 생각:

- FeverLog(GPL) — 체온 오르내림 표시 · 소변 기록 경고는 Fever-out, 투약 직후 공유 글은 smartdose, 그래프 PNG 는 fiebertagebuch
- 가족 공유를 만들 때: baby-tracker(초대 코드 = 권한, 계정 없음), NestHealth(AGPL — 60초 폴링 · 의존성 없는 VAPID 웹 푸시)
- 라이선스 없는 저장소(fiebertagebuch · smartdose · Fever-out)는 코드를 쓸 권리가 없다
